02 — ABOUT

About the Project

California Watches is a modern e-commerce web application built around a premium watch brand. The project focuses on creating a clean shopping experience with product browsing, collections, search, user accounts and cart functionality.

03 — FEATURES

Features

  • Modern watch e-commerce interface
  • Product browsing and collections
  • Product search functionality
  • User login and registration
  • Shopping cart functionality
  • Responsive design
