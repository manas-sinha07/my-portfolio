02 — PROJECT

Employee & User Management

A web application for managing employees and users

1 / 5

01 — OVERVIEW

About the Project

Employee & User Management is a web application Named Manage Pro designed to manage employee and user information through a structured web interface. The project uses Spring Boot for the backend, Thymeleaf for the frontend, and MySQL for data persistence.

02 — FEATURES

Features

  • Add employee information
  • View employee records
  • Update employee information
  • Delete employee records
  • User management
  • Form validation
  • Database integration

03 — TECHNOLOGIES

Tech Stack

Java Spring Boot Thymeleaf JPA Hibernate MySQL HTML CSS
